# Yahoo!リアルタイム検索 感想集計ツール

Yahoo!リアルタイム検索に出てくる公開投稿（X の投稿）を定期的に集め、イベントの感想を集計します。
初期設定は「声グラハロウィーン」用です（`config.json`）。

集計結果は `reports/report.html`（ブラウザで開くレポート）と CSV（Excel で開ける）に出力します。

- 時間帯ごとの投稿数とピーク
- 感想の傾向（最高・楽しい／かわいい・かっこいい／感動・尊い／不満・要望 など）
- 注目ワード（出演者名・グッズ・配信など、自分で登録した語）
- よく使われた言葉・ハッシュタグ・絵文字のランキング
- 反応（いいね・リポスト）の多い投稿

## 必要なもの

- Windows 10/11（Mac・Linux でも動きます）
- Python 3.10 以上: <https://www.python.org/> からインストール。途中の「Add python.exe to PATH」にチェックを入れる
- （任意）形態素解析ライブラリ janome。入れると「よく使われた言葉」の精度が上がります

  ```
  py -m pip install janome
  ```

ほかに追加のインストールは要りません。

## 使い方（イベント当日）

このフォルダ（`realtime_aggregator`）の中のファイルをダブルクリックします。

1. **`doctor.bat`** … Yahoo から投稿を取得できるかを確認します。最初に 1 回実行してください。
   すべて `OK` なら準備完了です。`NG` が出たら、下の「うまく動かないとき」を見てください。
2. **`collect.bat`** … 収集を始めます。60 秒ごとに最新の投稿を取得し、
   `data/seigura_halloween.sqlite3` に保存します。取得のたびに `reports/report.html` も更新されるので、
   ブラウザで開いて再読み込みすれば途中経過を見られます。止めるときは `Ctrl + C` を押します。
   イベント終了後も、感想が落ち着くまで動かしておくのがおすすめです。
3. **`report.bat`** … 集計して、レポートをブラウザで開きます。

collect を止めて再開しても、それまでのデータに追加されます。同じ投稿は 1 件として数えます。

### 出力されるファイル（`reports/`）

| ファイル | 内容 |
| --- | --- |
| `report.html` | 集計レポート（ブラウザで表示） |
| `posts.csv` | 集計対象の投稿一覧。投稿ごとに当てはまる「注目ワード」「感想の傾向」の列付き |
| `timeline.csv` | 時間帯ごとの投稿数 |
| `words.csv` / `hashtags.csv` | 言葉・ハッシュタグのランキング |
| `groups.csv` | 感想の傾向・注目ワードの件数と割合 |

CSV は BOM 付き UTF-8 なので、Excel でダブルクリックしても文字化けしません。

## 設定ファイル（`config.json`）

メモ帳などで編集できます。日時はすべて日本時間で、`"2026-10-24 18:00"` の形で書きます。

| 項目 | 意味 |
| --- | --- |
| `event_name` | レポートのタイトル |
| `queries` | 検索語（複数可）。表記ゆれ（ハロウィーン／ハロウィン）は両方入れておくと漏れが減ります |
| `since` / `until` | 集計する期間。`until` を設定すると collect はその時刻に自動停止します。`null` で指定なし |
| `interval_seconds` | 最新の投稿を取りに行く間隔（秒）。20 秒未満にはできません |
| `backfill_max_pages` | 取りこぼしを補うとき、1 回にさかのぼる最大ページ数。`0` でさかのぼらない |
| `request_delay_seconds` | Yahoo へのリクエストどうしの最低間隔（秒） |
| `bucket_minutes` | 時間帯グラフの区切り（分）。期間が長いと自動で広げます |
| `keywords` | 注目ワード。`"表示名": ["照合する語", ...]` の形。**出演者名と愛称をここに追加してください** |
| `reactions` | 感想の傾向の分類。形は `keywords` と同じ |
| `exclude_words` | この語を含む投稿は集計から外します（初期値はチケット譲渡の投稿よけ） |
| `exclude_users` | 集計から外すアカウント（公式アカウントの告知など）。`"@seigura"` のように書きます |
| `stopwords` | 「よく使われた言葉」から外す語 |
| `dedupe_same_text` | 本文がまったく同じ投稿（URL 違いのみを含む）は 1 件だけ数える |
| `anonymize` | `true` にするとレポートと CSV でアカウント名を伏せ、投稿へのリンクを出しません |

注目ワードの例:

```json
"keywords": {
  "出演者A": ["出演者A", "Aさん", "愛称A"],
  "グッズ・物販": ["グッズ", "物販", "完売"]
}
```

照合では全角・半角と英字の大文字・小文字を区別しません。「1 件の投稿にその語が 1 つでも含まれるか」で数えます。

## 取りこぼしを補う（HAR の取り込み）

collect を動かしていなかった時間帯の投稿は、collect が自動でさかのぼって補います。
ただし、さかのぼりに使う Yahoo の読み込み口は公開仕様ではありません。`doctor` でさかのぼりが
`NG` になった場合は、ブラウザで表示した内容を保存して取り込めます。

1. Chrome か Edge で Yahoo!リアルタイム検索を開き、検索語で検索する
2. `F12` で開発者ツールを開き、「ネットワーク（Network）」タブを選ぶ
3. 検索結果を下までスクロールして、補いたい時間帯まで読み込ませる
4. ネットワークタブの「HAR をエクスポート（Export HAR）」ボタンで `.har` ファイルを保存する
5. 保存した `.har` ファイルを **`import.bat` にドラッグ＆ドロップ**する

コマンドで実行する場合は次のとおりです。

```
py -m yahoo_rt import -c config.json 保存したファイル.har
```

## コマンド

`realtime_aggregator` フォルダで実行します。`-q`・`--since` などは `config.json` の値より優先されます。

```
py -m yahoo_rt doctor  -c config.json
py -m yahoo_rt collect -c config.json [--live-report] [--once] [--interval 秒] [--max-pages N]
py -m yahoo_rt report  -c config.json [--since "2026-10-24 17:00"] [--until "2026-10-25 06:00"] [--anonymize] [--open]
py -m yahoo_rt import  -c config.json ファイル... [--label 検索語]
```

## うまく動かないとき

- **`doctor` で「接続できませんでした」**: インターネット接続や、社内ネットワークのプロキシ設定を確認してください。
- **`doctor` で「投稿データが見つかりません」**: Yahoo のページ構造が変わった可能性があります。
  `debug/` フォルダに保存されたファイルを添えて相談してください。ファイルには検索結果の投稿が含まれます。
- **件数が少ない**: Yahoo!リアルタイム検索で表示される範囲の投稿だけを数えています。
  X の全投稿ではありません。鍵付きアカウントの投稿も含まれません。

## 集計の考え方と注意

- 件数はすべて「投稿の数」です。1 件の投稿が複数の分類に当てはまることがあります。
- リポスト、除外ワードを含む投稿、同じ本文の重複は集計から外し、外した件数をレポートに表示します。
- いいね数などは、最後に取得した時点の値です。
- このツールは Yahoo!リアルタイム検索の画面を自動で読み取ります。Yahoo の公式 API ではないため、
  仕様変更で動かなくなることがあります。アクセスは 1 本ずつ、間隔をあけて行います。間隔を短くしすぎないでください。
- 集めた投稿には個人のアカウント名と本文が含まれます。レポートを外部に公開するときは
  `--anonymize` を付け、引用の範囲に気をつけてください。`data/`・`reports/`・`debug/` は Git の管理対象外です。

## 開発者向け

```
python -m unittest discover -s tests
```

| モジュール | 役割 |
| --- | --- |
| `yahoo_rt/fetcher.py` | Yahoo への HTTP アクセス（間隔の確保、再試行） |
| `yahoo_rt/parser.py` | ページ内の `__NEXT_DATA__`、API の JSON、HAR から投稿を取り出す |
| `yahoo_rt/collector.py` | 定期取得と、取りこぼし時のさかのぼり取得 |
| `yahoo_rt/store.py` | SQLite への保存（同じ投稿は上書き） |
| `yahoo_rt/analyze.py` | 除外・重複除去と各種集計 |
| `yahoo_rt/report.py` | HTML・CSV・コンソール出力 |

parser は JSON の決まった位置をたどらず、「数字の ID・本文・投稿日時」を持つ要素を投稿とみなして探します。
ページ構造が多少変わっても動き続けるようにするためです。
