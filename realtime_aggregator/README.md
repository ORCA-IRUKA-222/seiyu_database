# Yahoo!リアルタイム検索 集計ツール

Yahoo!リアルタイム検索に出てくる公開投稿（X の投稿）を、キーワードと期間を指定して集め、
CSV とレポートにまとめる Windows 用のソフトです。

- キーワードの表記ゆれ（声グラ／声優グランプリ、ハロウィーン／ハロウィン など）をまとめて検索
- 見つかった投稿をすべて CSV に保存（集計から外した投稿も、外した理由つきで残す）
- 集計レポート: 時間帯ごとの投稿数、感想の傾向、注目ワード、よく使われた言葉・ハッシュタグ・絵文字、反応の多い投稿

## 必要なもの

- Windows 10/11（Mac・Linux でも動きます）
- Python 3.10 以上: <https://www.python.org/> からインストールします。
  途中の「Add python.exe to PATH」にチェックを入れてください。「tcl/tk and IDLE」は最初からチェックが入っているので、そのままにします
- （任意）形態素解析ライブラリ janome。入れると「よく使われた言葉」の精度が上がります

  ```
  py -m pip install janome
  ```

## 使い方

`realtime_aggregator` フォルダの **`app.bat`** をダブルクリックすると、検索の画面が開きます。

1. **名前** … 保存するファイルとレポートの題名に使います（例: 声グラハロウィーン2026）。
2. **キーワード** … 1 行に 1 つ入力します。空白で区切ると「すべての語を含む」投稿を探します。
3. **表記ゆれ** … 同じ意味の語を `=` でつなぎます。1 行に 1 組です。

   ```
   声グラ = 声優グランプリ
   ハロウィーン = ハロウィン
   ```

   「キーワードを表記ゆれの語で区切って探す」にチェックがあると、キーワード「声グラハロウィーン」を
   下の 4 通りに広げて検索します。「声グラさんのハロウィンイベント」のように語が離れている投稿も見つかります。
   実際に検索する語は、画面の「検索する語」の欄で確かめられます。

   ```
   声グラ ハロウィーン ／ 声グラ ハロウィン ／ 声優グランプリ ハロウィーン ／ 声優グランプリ ハロウィン
   ```

4. **期間** … `2026-10-24 00:00` の形で入力します。終わりを空欄にすると現在までです。
   「今日」「24時間」「7日間」のボタンでも入れられます。
5. **集計から外す** … 公式アカウントの告知や、取引の投稿（【交換】、譲：〇〇 求：〇〇 など）を集計から外します。
   外した投稿も一覧と CSV には残り、「集計」の列に理由が出ます。
6. **注目ワード** … レポートで件数を数えたい語です。出演者名などを `薬師寺李有 = 李有` のように書きます。
7. **検索** を押します。期間の始まりまでさかのぼって集め、一覧に表示します。

検索のあとは次のことができます。

- **CSVに保存…** … 見つかった投稿をすべて CSV に保存します（保存先は選べます）。
- **レポートを開く** … 集計レポートをブラウザで開きます。
- **保存フォルダを開く** … レポートと CSV 一式のフォルダ（`reports/名前/`）を開きます。
- 一覧の行を選ぶと本文全体が表示され、ダブルクリックするとその投稿をブラウザで開きます。

イベントの最中に使うときは、「検索のあとも 60 秒ごとに新しい投稿を取りに行く」にチェックを入れて検索します。
止めるときは **停止** を押します。いいね数は取得した時点の値なので、最後にもう一度「検索」を押すと最新になります。

入力した内容は、次に開いたときにも残っています（`gui_settings.json`）。

### CSV の列

| 列 | 内容 |
| --- | --- |
| 投稿日時・投稿ID・アカウント・表示名・本文 | 投稿の情報 |
| いいね・リポスト・引用・返信 | 最後に取得した時点の数 |
| ハッシュタグ | 本文のハッシュタグ |
| 一致した検索語 | その投稿が見つかった検索語 |
| 集計・除外した理由 | 「対象」か「除外」。除外のときは理由（除外アカウント、取引の投稿、除外ワード、リポスト、同じ本文の重複） |
| URL | 投稿のページ |

CSV は BOM 付き UTF-8 なので、Excel でダブルクリックしても文字化けしません。

### `reports/名前/` に出力されるファイル

| ファイル | 内容 |
| --- | --- |
| `report.html` | 集計レポート |
| `all_hits.csv` | 見つかったすべての投稿（上の「CSV の列」と同じ形） |
| `posts.csv` | 集計の対象になった投稿だけ。当てはまる「注目ワード」「感想の傾向」の列付き |
| `timeline.csv` / `words.csv` / `hashtags.csv` / `groups.csv` | 時間帯ごとの件数、言葉・ハッシュタグのランキング、分類ごとの件数 |

## 困ったとき

- **`doctor.bat`** … Yahoo から投稿を取得できるかを診断します。画面で検索がうまくいかないときに実行してください。
  「間を飛ばさずに取得できました」と出れば、過去の投稿をさかのぼる処理も正常です。
- **「接続できませんでした」** … インターネット接続や、社内ネットワークのプロキシ設定を確認してください。
- **「投稿データが見つかりません」** … Yahoo のページ構造が変わった可能性があります。
  `debug/` フォルダに保存されたファイルを添えて相談してください。ファイルには検索結果の投稿が含まれます。
- **件数が少ない** … Yahoo!リアルタイム検索で表示される範囲の投稿だけを数えています。
  X の全投稿ではありません。鍵付きアカウントの投稿も含まれません。

### 取りこぼしを補う（HAR の取り込み）

さかのぼり取得が使えない場合は、ブラウザで表示した内容を保存して取り込めます。

1. Chrome か Edge で Yahoo!リアルタイム検索を開き、検索語で検索する
2. `F12` で開発者ツールを開き、「ネットワーク（Network）」タブを選ぶ
3. 検索結果を下までスクロールして、補いたい時間帯まで読み込ませる
4. ネットワークタブの「HAR をエクスポート（Export HAR）」ボタンで `.har` ファイルを保存する
5. 保存した `.har` ファイルを **`import.bat` にドラッグ＆ドロップ**する

## 集計の考え方と注意

- 件数はすべて「投稿の数」です。1 件の投稿が複数の分類に当てはまることがあります。
- 照合では全角・半角と英字の大文字・小文字を区別しません。
- このツールは Yahoo!リアルタイム検索の画面を自動で読み取ります。Yahoo の公式 API ではないため、
  仕様変更で動かなくなることがあります。アクセスは 1 本ずつ、間隔をあけて行います。
- 集めた投稿には個人のアカウント名と本文が含まれます。レポートを外部に公開するときは
  アカウント名を伏せ（コマンドの `--anonymize`）、引用の範囲に気をつけてください。
  `data/`・`reports/`・`debug/`・`gui_settings.json` は Git の管理対象外です。

## コマンドで使う場合（`config.json`）

画面を使わず、設定ファイルで動かすこともできます。初期設定は「声グラハロウィーン」用です。

| ファイル | 内容 |
| --- | --- |
| `collect.bat` | 60 秒ごとに新しい投稿を取得し続けます（`Ctrl + C` で停止） |
| `refresh.bat` | `since` までさかのぼって取り直し、いいね数を最新にしてレポートを作ります |
| `report.bat` | 集計してレポートを開きます |

```
py -m yahoo_rt gui
py -m yahoo_rt doctor  -c config.json
py -m yahoo_rt collect -c config.json [--live-report] [--once] [--interval 秒] [--max-pages N]
py -m yahoo_rt collect -c config.json --refresh [--live-report] [--max-pages N]
py -m yahoo_rt report  -c config.json [--since "2026-10-24 17:00"] [--until "2026-10-25 06:00"] [--anonymize] [--open]
py -m yahoo_rt import  -c config.json ファイル... [--label 検索語]
```

`config.json` の主な項目（日時は日本時間）:

| 項目 | 意味 |
| --- | --- |
| `event_name` | レポートのタイトル |
| `queries` | キーワード（複数可） |
| `synonyms` | 表記ゆれ。`[["声グラ", "声優グランプリ"], ["ハロウィーン", "ハロウィン"]]` の形。登録するとキーワードを画面と同じ規則で広げます |
| `since` / `until` | 集計する期間。`until` を設定すると collect はその時刻に止まります |
| `interval_seconds` | 新しい投稿を取りに行く間隔（秒、20 以上） |
| `backfill_max_pages` | 取りこぼしを補うとき、1 回にさかのぼる最大ページ数（1 ページ約 40 件） |
| `keywords` | 注目ワード。`"表示名": ["照合する語", ...]` |
| `reactions` | 感想の傾向の分類。形は `keywords` と同じ |
| `exclude_users` / `exclude_words` | 集計から外すアカウント・語 |
| `exclude_trades` | `true` なら取引の投稿（【交換】、譲：〇〇 求：〇〇 など）を集計から外す |
| `dedupe_same_text` | 本文がまったく同じ投稿は 1 件だけ数える |
| `anonymize` | `true` ならレポートと CSV でアカウント名を伏せ、投稿へのリンクを出さない |

## 開発者向け

```
python -m unittest discover -s tests
```

| モジュール | 役割 |
| --- | --- |
| `yahoo_rt/gui.py` | 検索の画面（tkinter） |
| `yahoo_rt/search.py` | 画面から使う検索処理（入力の確認、検索、結果の読み込み） |
| `yahoo_rt/variants.py` | 表記ゆれの展開 |
| `yahoo_rt/fetcher.py` | Yahoo への HTTP アクセス（間隔の確保、再試行） |
| `yahoo_rt/parser.py` | ページ内の `__NEXT_DATA__`、API の JSON、HAR から投稿を取り出す |
| `yahoo_rt/collector.py` | 定期取得と、さかのぼり取得 |
| `yahoo_rt/store.py` | SQLite への保存（同じ投稿は上書き） |
| `yahoo_rt/analyze.py` | 除外・重複除去と各種集計 |
| `yahoo_rt/report.py` | HTML・CSV・コンソール出力 |

さかのぼり取得では、直前のページの最後の投稿が次のページの先頭に重なるように頼み、
ページの間を飛ばしていないことを毎回確かめます。重ならなかったときは画面とログに知らせます。
